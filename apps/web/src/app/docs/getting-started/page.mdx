# Getting Started

visual-yaml is the visual JSON editor. Schema-aware, embeddable, extensible. It provides tree view, form view, diff view,
and raw editing modes — all powered by a headless core library with React and Vue components.

## Installation

Install the core library and your framework's components:

```bash
# React
npm install @visual-yaml/core @visual-yaml/react

# Vue
npm install @visual-yaml/core @visual-yaml/vue
```

## Quick Start (React)

Wrap your UI in the `VisualYaml` provider, then use any combination of the built-in components:

```tsx
import { VisualYaml, TreeView, FormView } from "@visual-yaml/react";
import { useState } from "react";

function Editor() {
  const [value, setValue] = useState({ hello: "world" });

  return (
    <VisualYaml value={value} onChange={setValue}>
      <div style={{ display: "flex", gap: 16 }}>
        <TreeView />
        <FormView />
      </div>
    </VisualYaml>
  );
}
```

## Quick Start (Vue)

Same pattern — the `VisualYaml` component provides state to all child components:

```vue
<script setup>
import { ref } from "vue";
import { VisualYaml, TreeView, FormView } from "@visual-yaml/vue";

const value = ref({ hello: "world" });
</script>

<template>
  <VisualYaml :value="value" @change="value = $event">
    <div style="display: flex; gap: 16px">
      <TreeView />
      <FormView />
    </div>
  </VisualYaml>
</template>
```

The `VisualYaml` component manages all internal state — tree structure, selection,
expand/collapse, undo/redo, search, and schema. Child components read from and
write to this shared context automatically.

## View Modes

visual-yaml supports multiple ways to view and edit your data:

- **Tree View** — Hierarchical tree with expand/collapse, drag-and-drop reordering, keyboard navigation, and context menus
- **Form View** — Schema-aware form editor with descriptions, required fields, and enum dropdowns
- **Diff View** — Side-by-side comparison of original vs. edited YAML, with color-coded additions, removals, and changes
- **Raw View** — Direct text editing of the underlying YAML

## VS Code Extension

visual-yaml is also available as a VS Code extension. Open any `.json` or `.jsonc` file,
right-click the tab, and choose **"Open With..." > "visual-yaml"** to use the visual editor.

The extension includes a tree sidebar, form editor, schema support (auto-detected from
`$schema` or known filenames like `docker-compose.yaml` and `github-workflow.yaml`), and adapts to your
VS Code theme colors automatically.
